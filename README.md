# 🩺 MediCare – Medicine Reminder App

MediCare is a modern and user-friendly **Medicine Reminder & Schedule App** designed to help users manage their daily medications, reminders, schedules, and health information.

## 📱 Project Overview

MediCare is a **Healthcare UI/UX project** created as an internship/portfolio project.

The main goal is to make medicine management simple by providing reminders, medication schedules, dose tracking, refill alerts, and emergency health information in one application.

## ✨ Features

* 💊 Medicine reminder and scheduling
* 🌅 Morning, ☀️ Afternoon and 🌙 Night time slots
* ✅ One-tap medicine "Taken" confirmation
* 🔔 Active medicine alarm
* ⏰ 15-minute snooze/reminder option
* 📦 Medicine refill and stock tracking
* 🚨 Low-stock alerts
* 🏥 Emergency medical profile
* ⚠️ Allergy information
* 👨‍⚕️ Physician and emergency contact information
* 🌙 Dark and Light mode
* 🔊 Medical audio chimes
* 👨‍👩‍👧 Caregiver notification support

## 📲 App Screens

The project contains **8 interactive screens**:

1. Splash Screen
2. Login / Sign Up
3. Home Dashboard
4. Add Medicine

6. Medicine Details
